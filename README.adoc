== ⚡ TL;DR

* 🗂️ Chaque sous-dossier (`python/`, `asciidoc/`, `scripts/adoc_link_check/`) est autonome, avec son propre `requirements.txt`/environnement virtuel
* 🎯 Quand : pour récupérer un bout de code ou une doc déjà écrite plutôt que de la réécrire #flemme #DRY
* 🚀 `cd scripts/adoc_link_check && python cli.py .` — vérifie les liens cassés dans les fichiers AsciiDoc du dépôt courant

Ce document rassemble des bouts de code qui peuvent être utiles à réutiliser pour gagner du temps #flemme #DRY.

Il se compose d'un dossier :

* 🐍 link:python[python] ;
* 📝 link:asciidoc[asciidoc] pour réécrire facilement des fichiers asciidoc ;
* 🔗 link:scripts/adoc_link_check[scripts/adoc_link_check] pour vérifier les liens cassés dans les fichiers AsciiDoc.

Pour choisir les composants d'un ordinateur que l'on souhaite construire, on peut utiliser le site https://fr.pc-builder.io/[PC Builder].

== 🚀 Installation

[source,bash]
----
cd scripts/adoc_link_check
pip install -r requirements.txt
----

== 💻 Utilisation

[source,bash]
----
python cli.py [directory] [--timeout 15] [--max-workers 5] [--verbose]
----
